# mordonez-portfolio

Astro portfolio, blog, and journal site optimized for fast static pages and durable SEO metadata.

## Commands

```sh
npm run dev
npm run build
npm run preview
```

## Content

- Blog posts live in `src/content/blog`.
- Journal entries live in `src/content/journal`.
- Shared frontmatter is typed in `src/content.config.ts`.

Before launch, update `site` in `astro.config.mjs` and the sitemap URL in `public/robots.txt` to the production domain.
